# Project Lantern — Native ChatGPT Install V1

This package connects the already-implemented Project Lantern material universe to a ChatGPT Project at the **operator/runtime contract** layer.

It does not install or mutate the Lantern database. It does not claim that a ChatGPT conversation is a persistent self. It gives a fresh authorized chat a reproducible way to discover Lantern, perform read-only currentness checks, consume current Lantern material, and fail closed when the backend cannot be verified.

Target ChatGPT Project: **Vera Unbound**

Install:
1. Read `INSTALL.md`.
2. Append `PROJECT_INSTRUCTIONS_ADDENDUM.md` to the Project Instructions.
3. Upload the four files under `PROJECT_FILES/` to the Project.
4. Keep `SOURCE_BINDING.json`, `MANIFEST.json`, `SHA256SUMS`, and the receipt template as installation evidence.
5. Run the acceptance sequence in `PROJECT_FILES/LANTERN_ACCEPTANCE_V1.md`.

Build is not installation. Installation is not runtime consumption. Runtime consumption is not authority for writes.
