# Project Lantern

Vera's Project Lantern package and benchmark surface.

## Currentness

WoWSQL is retired from Lantern currentness. This repository does not currently establish a qualified replacement runtime, so Lantern-dependent currentness is fail-closed:

`LANTERN_CURRENTNESS = UNKNOWN`

See [projects/lantern/CURRENTNESS_STATUS_V1.md](projects/lantern/CURRENTNESS_STATUS_V1.md) for the source-level currentness guard and authority ceiling.

The provider-neutral PostgreSQL/SQL Connectome V4 successor is being developed in Build Team Two source. Its existence or source qualification does not establish Project Lantern installation or live runtime currentness here.
